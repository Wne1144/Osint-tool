Wichtiger Hinweis: MVP für zulässige, verhältnismäßige Recherche. Bei einer Suche werden die ausgewählten Begriffe direkt aus deinem Browser an die öffentliche Wikipedia-Such-API übermittelt. Treffer sind Hinweise, keine Identitätsbestätigung. Keine Gesichtssuche, kein Scraping, keine geleakten Datenbanken. Der Score ist keine Identitätswahrscheinlichkeit.

Quellen & Grenzen

Wikipedia MediaWiki API — kostenlos, ohne Schlüssel, automatisiert; öffentliche Enzyklopädie-Suche, begrenzte Aussagekraft, Anbieterbedingungen beachten. API-Abfrage nur nach Nutzeraktion. Kein Anspruch auf Vollständigkeit.

Manuelle Suche — wird als Google-Suchlink angeboten; du verlässt dann diese Seite und Google erhält die Anfrage.

PimEyes / Gesichtssuche — nicht integriert; kein Upload, keine Biometrie.

Keine externe KI, keine Scraping-Umgehung, keine geleakten Datenbanken.

So funktioniert der Score

Heuristik 0–100, exakt wie in der Python-Version: Token-Überlappung (max. 45) + exakte Phrase (20) + fester Quellenbeitrag Wikipedia (15) + Spezifität (max. 10) + unabhängige Belege (derzeit 0) − Unsicherheitspauschale (10).

Kein Wahrscheinlichkeitswert: Auch 80+ bestätigt keine Identität. Die Faktoren jedes Treffers werden offen angezeigt.

Wähle ein Projekt

Lege links ein Projekt an oder wähle ein vorhandenes aus. Ohne ausgewählte Suchbegriffe (Name/E-Mail/Handle) kann keine Recherche laufen — das wird als Fehler protokolliert, nicht als „keine Informationen vorhanden“.

Abfragen & Läufe

Noch keine Recherche ausgeführt. Jede Wikipedia-Abfrage (Iteration, Herkunft, Status) wird hier protokolliert — auch technische Fehler.

Lokaler Datenschutz

Speicherort dieser Web-Version: localStorage deines Browsers (Schlüssel localosint.web.v1) — kein Server, kein Tracking, keine Cookies. Der ursprüngliche SQLite-/Loopback-Schutz der Python-Version (Token, Host-/Origin-Check) entfällt, weil es keinen lokalen Server mehr gibt; dafür verlässt außer den Wikipedia-Suchbegriffen (nur nach deiner Bestätigung und Klick) nichts das Gerät.

Projektlöschung und vollständige Löschung sind verfügbar. Für hochsensible Löschung zusätzlich die Browser-Website-Daten löschen.

Desktop-/Offline-Variante: Die originale Python-Version liegt im Repo unter LocalOSINT/ (python3 app.py, nur Standardbibliothek, bindet nur an 127.0.0.1).
